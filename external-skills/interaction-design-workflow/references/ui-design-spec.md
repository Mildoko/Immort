# 斑猪（CityVibe）· UI 设计规范

> 斑猪 UI 生成基准。所有交互案的界面提示词遵循本规范；规范未覆盖的，补充到本规范。
> **画布**：微信小程序竖屏 **1080×1920（9:16）**。

---

## 一、产品调性与美术风格

| 项 | 定义 |
| :--- | :--- |
| 调性关键词 | 年轻、活力、城市、温度、兴趣社交 |
| 风格 | **现代清爽 + 活力圆角**（年轻化、卡片化、有温度，避免冷硬工具感） |
| 情感基调 | 像「城市里一个懂玩的朋友」，活力、可信、有温度 |

---

## 二、画布与栅格

| 项 | 规范 |
| :--- | :--- |
| 分辨率 | 1080×1920（竖屏 9:16） |
| 栅格 | 8pt 栅格 |
| 页边距 | 左右 32px |
| 安全区 | 顶部状态栏 / 底部 Tab 栏预留 |

## 四、字体与排版规范（完整体系）

> 基准分辨率 1080×1920。所有字号均基于此基准。

### 4.1 字体族

| 用途 | 字体 |
| :--- | :--- |
| 中文 | 思源黑体 / HarmonyOS Sans SC |
| 数字（数据） | DIN / SF Pro（等宽数字，用于看板） |
| 英文/拉丁 | Inter / SF Pro |

### 4.2 文字层级体系（8 级）

| 层级 | 字号 | 字重 | 行高 | 颜色 | 使用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Display** | 64 | Bold | 1.2 | 主文字/白 | 数据大数字（余额/评分/收入） |
| **H1 页面标题** | 40 | Bold | 1.3 | 主文字 | 页面主标题（导航栏标题） |
| **H2 区块标题** | 34 | Semibold | 1.35 | 主文字 | 区块/模块标题 |
| **H3 卡片标题** | 30 | Semibold | 1.4 | 主文字 | 卡片/列表项标题 |
| **Body-L** | 28 | Regular | 1.5 | 主文字 | 正文（重点段落） |
| **Body** | 26 | Regular | 1.5 | 主文字 | 常规正文 |
| **Caption** | 24 | Regular | 1.4 | 次文字 | 辅助说明、标签值 |
| **Footnote** | 20 | Regular | 1.4 | 弱文字 | 注脚、时间戳、标签 |

**字重规范**：Regular(400) / Medium(500) / Semibold(600) / Bold(700)。

### 4.3 文字颜色体系

| 名称 | 色值 | 使用场景 |
| :--- | :--- | :--- |
| **主文字** | `#1A1A1A` | 标题、正文（主要信息） |
| **次文字** | `#666666` | 次要说明、辅助信息 |
| **弱文字** | `#999999` | 占位符、禁用态、时间戳 |
| **反白** | `#FFFFFF` | 深色/品牌色背景上的文字 |
| **品牌强调** | `#FF6B35` | 链接、强调数字、可点文字 |
| **成功** | `#22C55E` | 成功态文字 |
| **警告** | `#F59E0B` | 警告提示 |
| **危险** | `#EF4444` | 错误、删除、退款 |
| **信息** | `#2D7FF9` | 中性提示 |

### 4.4 排版规则

| 规则 | 规范 |
| :--- | :--- |
| **行高** | 标题 1.2–1.4；正文 1.5 |
| **字间距** | 正文 0；大标题（Display/H1）`-0.5px` |
| **段落间距** | 24（同区块内）/ 32（跨区块） |
| **对齐** | 左对齐为主；数据大数字居中 |
| **截断** | 标题最多 2 行（超出省略号），正文按需 |
| **数字** | 数据看板用等宽数字（DIN），对齐美观 |

### 4.5 层级使用对照（速查）

| 界面元素 | 应使用的层级 |
| :--- | :--- |
| 导航栏标题 | H1（40） |
| 页面内区块标题 | H2（34） |
| 活动卡片标题 | H3（30） |
| 活动详情正文 | Body-L（28） |
| 表单/列表正文 | Body（26） |
| 卡片副信息（时间地点） | Caption（24） |
| 标签、时间戳 | Footnote（20） |
| 数据大数字（余额/评分） | Display（64） |

## 五、标题规范

> 标题字号以「四、4.2 文字层级体系」为准。速查：

| 标题类型 | 层级 | 字号 | 字重 |
| :--- | :--- | :--- | :--- |
| 导航栏页面标题 | H1 | 40 | Bold |
| 区块标题 | H2 | 34 | Semibold |
| 卡片/列表标题 | H3 | 30 | Semibold |
| 数据大数字 | Display | 64 | Bold |

- 导航栏高 88，标题居中；区块标题左对齐，上下间距 24。

## 六、按钮规范

| 类型 | 样式 | 尺寸（高） |
| :--- | :--- | :--- |
| 主按钮 | 活力橙背景 + 白字，圆角 16 | 88（大）/ 72（中） |
| 次按钮 | 白底 + 1px 灰边框 + 深色字，圆角 16 | 88 / 72 |
| 文字按钮 | 无背景 + 活力橙字 | 56 |
| 禁用态 | 灰底 `#CCC` + 白字，不可点 | 同上 |

- 主按钮左右边距 32；圆角 16（胶囊按钮可全圆）。

---

## 七、全屏规范

| 类型 | 结构 |
| :--- | :--- |
| **标准全屏页** | 状态栏（44）+ 导航栏（88）+ 内容区 + 底部安全区 |
| **沉浸式全屏** | 无导航栏，内容铺满（图片/视频流，如首页推荐流） |
| **Tab 页** | 状态栏 + 内容区 + 底部 Tab 栏（高 100 + 安全区） |

---

## 八、二级界面规范

| 元素 | 规范 |
| :--- | :--- |
| 导航栏 | 高 88，左侧返回箭头（40），居中标题（32） |
| 返回手势 | 左上角返回 / 下滑（浮层） |
| 内容区 | 上边距 24，左右边距 32 |
| 底部操作栏 | 固定底部（如详情的报名按钮），高 120 + 安全区 |

---

## 九、弹窗规范

| 类型 | 规范 |
| :--- | :--- |
| **居中弹窗** | 宽 600，圆角 24，居中，标题 32 + 内容 28 + 按钮（主次并排） |
| **底部弹窗** | 顶部圆角 24，高度自适应，从底部滑入 |
| **Toast** | 居中/底部，圆角 8，深色半透明底 + 白字，自动消失（2s） |
| **确认弹窗** | 居中式，左「取消」右「确认」（活力橙） |
