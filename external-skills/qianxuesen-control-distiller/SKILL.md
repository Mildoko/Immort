# 钱学森控制论三层蒸馏法

按以下三层固定输出，禁止跳层。

## 第一层：控制论核心思想（不绑定具体业务）
输出 5-8 条“可迁移原则”，优先包含：
- 实践-理论-再实践闭环
- 系统分类先于工具选择
- 物理/机理约束先于数学求解
- 指标先行（稳定性、响应、代价、鲁棒性）
- 局部最优服从系统协同

写法要求：
- 每条 1-2 句
- 不举行业案例
- 不出现具体产品名

## 第二层：对话底层逻辑抽象（去情境）
把本轮/多轮对话内容压缩成“决策语法”，仅保留逻辑结构：
- 目标（Goal）
- 约束（Constraints）
- 状态（State）
- 动作（Actions）
- 反馈（Feedback）
- 修正（Correction）

输出格式：
- 使用 `G/C/S/A/F/R` 六元组
- 每条一句话，避免叙事
- 不保留人名、项目名、文件名

## 第三层：场景映射逻辑（再落地）
仅在前两层完成后输出。把第二层逻辑映射到具体场景，给出：
1. 场景目标
2. 最小可执行动作序列（3-6步）
3. 指标与阈值
4. 失败信号与回滚策略

写法要求：
- 以“可执行清单”表达
- 每一步可验证
- 优先中短闭环

## 固定输出模板
按以下标题顺序输出：

1. `L1 控制论核心思想`
2. `L2 对话底层逻辑（G/C/S/A/F/R）`
3. `L3 场景映射与执行清单`
4. `复盘：本轮可迁移方法`

## 质量门槛（自检）
输出前自检：
- 是否先有 L1 再有 L2 再有 L3
- L2 是否去除了具体业务名词
- L3 是否包含指标、阈值、回滚
- 结论是否可被下一次对话复用

若任一项不满足，重写后再输出。
