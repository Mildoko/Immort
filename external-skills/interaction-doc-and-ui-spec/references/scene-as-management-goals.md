# 场景即经营目标：坑位、分层母版、视口改向的资产复用

## 何时用

- 元游戏（复苏 / 建设 / 装修 / 岛屿经营）的场景是**玩家每天回来看的「家」**
- 场景从「界面里的一条横带」升级为「**通铺整屏的主角**」
- 需要把「经营目标」做成**看得见**的东西，而不是靠一份清单告诉玩家

---

## 一、坑位 = 经营目标 ★（本节核心）

**把「待建位」预先画进场景底图**，未建成时以「残破 / 空置」的形制存在 —— 玩家扫一眼就能数出「我还有几个地方要修」。

### 1.1 空态形制必须逐个点名

写进生成提示词，**每一项给具体形态 + 大致尺寸（px）**；不点名，AI 会画成一片干净的平地，坑位当场消失。

| 坑位 | 建成后 | **空态形制（要写进提示词）** |
| --- | --- | --- |
| 水源位 | 水晶湖 | 干涸的圆形凹坑（约 260 px）+ 夯土与散石坑壁 + 一截朽木 |
| 水利位 | 石桥与溪流 | 干涸的石砌渠床（约 420 px 空槽）+ 碎石 |
| 植被位 | 天空花园 | 裸露的根系坑（翻起的深色湿土）+ 枯立木桩（约 220 px）+ 网状根须印 |
| 聚落位 | 灯火夜市 | 一圈平坦空地（约 400 px）+ 半截帐篷桩 + 压石 |
| 圣所位 | 石砌台基 | 石砌台基 + 两根断柱（约 300 px），台基规整、断口粗糙 |

> 措辞要**「残破」而不是「整洁」**，否则模型会画成景观点缀而非待建目标。

### 1.2 坑位数 = **族位置数**，不是项目条目数 ★

实测：某复苏元游戏有 **23 个建设项目**，归入 **5 个族**（水源 / 水利 / 植被 / 聚落 / 圣所）。

- **坑位 = 5 个族位**，依据既有的「**同族升级 = 原位置换图**」纪律 ——
  A 族从第一口井到水晶湖**始终占同一个坑**，变的是体量 / 材质 / 装饰密度，**不是多长出一个东西**。
- 若按 23 个项目去画 23 个坑 ⇒ 画面变成拥挤的工地，且与「这是我一级级改出来的」认知直接冲突。
- 另加 6 个装饰位（挂载型，锚点由前端画虚线 / 锁），合计 11 个锚点。
- **可读性底线**：坑位位置在出图前就定死，中途改会让已出的族位资产全部对不上位。

### 1.3 三态必须分开（最容易混的一处）

| 态 | 含义 | 表现 |
| --- | --- | --- |
| **坑位（空）** | **内容还没做，但位置与形制已经给了** | 残破底座 / 空地；可见、可点 → 经营目标 |
| **预告态** | **功能还没做** | 降饱和 + 轻描边；点击轻提示「待开放」（`Coming soon`） |
| **禁用态** | **存在，但当前不满足条件** | `opacity .35` + `--dim`，不给点击反馈 |

> **用禁用态去画坑位 = 把「目标」画成「坏了」**，玩家会以为是 bug。
> 坑位要有**期待感**（残破但可修复），禁用态只有**拒止感**。

### 1.4 一屏可见的坑数随阶段增长

镜头随阶段**逐步拉远**，最终全部坑位同屏可见 —— 这正是「拉远」这个动作的叙事价值：
玩家看到的不是场景被替换，而是**自己的地方越来越大、越来越完整**。

## 二、两张母版（起点 + 终态）

| 母版 | 内容 | 用途 |
| --- | --- | --- |
| **M0 · 基底** | 天空 + 远景 + 中景地形 + **全部坑位空态** | 阶段零 / 新手第一眼；所有阶段的**合成底图**；**坑位的唯一来源** |
| **M1 · 终态** | 各族满级落位 | 「终态先行」的**减法基准** |

> ⚠️ **「终态先行」≠「只出终态」**。没有 M0，坑位就不存在，「坑位 = 经营目标」无从成立。
> M0 同时给减法链一个**明确的下限**（从终态往回减，减到的就是这个基底）。

---

## 三、场景何时通铺、何时只做取景

| 场景在 IA 中的角色 | 画布 | 取景方式 |
| --- | --- | --- |
| **界面里的一条信息带**（局内作业页仍有主体操作区，如棋盘） | 横版或扁条 | 扁条裁切 + 摄像机关键帧 |
| **通铺整屏的主角**（元游戏中枢页，没有其它主体操作区） | **竖屏全屏（跟随项目画布）** | 竖屏取景 + 随阶段拉远 |

**判据：场景是不是这一页唯一的主体。** 是 → 通铺；不是 → 取景。

> 连带：一旦从「取景」改成「通铺」，旧的扁条母版竖裁只会得到一条极窄的竖条 —— **母版必须重出**，且旧母版**转用途**（见下节）。

---

## 四、视口改向（横 → 竖）时的资产复用判据 ★

改画布方向时**不必全案重出**。按「资产是否与画布方向耦合」分类：

| 资产 | 改向时 | 理由 |
| --- | --- | --- |
| **独立物件图（方图，锚点居中）** | ✅ **可直接复用** | 单元素、锚点在画面正中，与画布方向无关 |
| **挂载型小件（装饰件等）** | ✅ **可复用** | 同上 |
| **母版本身** | ❌ **必须重出** | 构图与取景就是它的全部内容 |
| **只做「出现 / 不出现」两态的总图** | ❌ **需重出** | 原本从旧母版裁出，裁切位置随画布变了 |
| **旧母版** | ♻️ **转用途，不是废弃** | 商店截图 / 买量素材（16:9 正合适） |

**实测账**：旧方案 25 张 → 通铺方案 29 张，**净增 4 张**（多一张基底 + 三张两态总图）。

> **纪律：改画布方向时先做这张分类表，再对外报价 / 估工时** —— 否则会按「全案重出」估出约 3 倍成本，把一次可行改动估成不可行。

---

## 五、写进生成提示词的硬项（缺一项就会翻车）

1. 每个坑位的**空态形制逐个点名 + 大致尺寸（px）**
2. **地平线 y 坐标** + 沙地 / 绿量占比（给数字，不给形容词）
3. 「残破」而非「整洁」的措辞
4. 一票否决项：**无 3D、无写实光影、无照片素材、无人物、无现代建筑、无文字**
5. 锚点固定画面正中；**一张一级、独立出图**（不在一张图里画多个状态）

## 六、验收

| # | 验收项 | 通过标准 |
| --- | --- | --- |
| 1 | **坑位可见且可数** | 缩到游戏**实际显示尺寸的 1/2** 后，空坑仍能一眼数出来 —— 数不出来，「经营目标」就不成立 |
| 2 | **坑位不跳位** | 任一族位资产贴进对应坑位：锚点对齐、坑口容得下建成物 |
| 3 | **每级取景都成立** | 用 M0 / M1 各切三个取景（近景 / 中景 / 全景），每屏都有明确主体，且绿量随阶段提升 |
| 4 | 风格双轨合规 | 场景侧允许暖天光与轻微大气感、允许风格化镜像倒影；**禁强透视 / 明确消失点、禁写实材质** |

> **不通过时的修法**：**用已通过的那张做图生图参考**，而不是往提示词里加形容词。
