# UI 设计规范模板（UI Spec Starter）

> 复制此模板，按产品调性替换参数，作为「界面提示词」的统一基准。
> 规则：**先定规范，再写界面提示词；单个界面优先引用规范，规范未覆盖的补回规范。**

---

## 一、产品调性与美术风格

| 项 | 定义 |
| :--- | :--- |
| 调性关键词 | <年轻/活力/城市/温度…，由产品定位推导> |
| 风格 | <如「现代清爽 + 活力圆角」> |
| 情感基调 | <一句话，如「像城市里一个懂玩的朋友」> |

---

## 二、画布与栅格

| 项 | 规范 |
| :--- | :--- |
| 分辨率 | **1080×1920（9:16 竖屏，微信小程序基准）** |
| 栅格 | 8pt 栅格 |
| 页边距 | 左右 32px |
| 安全区 | 顶部状态栏 / 底部 Tab 栏预留 |
| 适配 | @2x/@3x |

> 注意：竖屏是 **1080×1920(9:16)**，横屏才是 1920×1080(16:9)。用户写「1920×1080 竖屏」时先 clarify。

---

## 三、色彩规范

**品牌色**：Primary / Primary-dark（按压态）/ Primary-light（浅底）——全给 HEX。
**辅助色**：1-2 个（如城市蓝、清新绿）。
**功能色**：成功 / 警告 / 危险 / 信息。
**中性色**：文字主 / 文字次 / 文字弱 / 页面背景 / 卡片 / 分割线。

| 名称 | 色值 | 用途 |
| :--- | :--- | :--- |
| Primary | `#FF6B35` | 主按钮、品牌元素 |
| Primary-dark | `#E85520` | 按压态 |
| Primary-light | `#FFF0EA` | 浅底、标签 |
| 城市蓝 | `#2D7FF9` | 信息、链接 |
| 文字主/次/弱 | `#1A1A1A`/`#666`/`#999` | |
| 页面背景 | `#F7F8FA` | 全局底色 |

---

## 四、字体与字号（1080 基准）

| 层级 | 字号 | 字重 | 用途 |
| :--- | :--- | :--- | :--- |
| 大标题 | 40 | Bold | 页面主标题、数据大数字 |
| 标题 | 32 | Semibold | 区块标题 |
| 小标题 | 28 | Medium | 列表标题 |
| 正文 | 28 | Regular | 正文 |
| 辅助 | 24 | Regular | 次要说明 |
| 注脚 | 20 | Regular | 标签 |

行高：标题 1.3，正文 1.5。

---

## 五、标题规范

| 类型 | 规范 |
| :--- | :--- |
| 页面标题（导航栏） | 32 Semibold，居中，导航栏高 88 |
| 区块标题 | 28 Semibold，左对齐，上下间距 24 |
| 列表标题 | 24 Medium |
| 数据标题 | 40 Bold（数据看板大数字） |

---

## 六、按钮规范

| 类型 | 样式 | 尺寸（高） |
| :--- | :--- | :--- |
| 主按钮 | Primary 背景 + 白字，圆角 16 | 88（大）/ 72（中） |
| 次按钮 | 白底 + 1px 灰边框 + 深色字，圆角 16 | 88 / 72 |
| 文字按钮 | 无背景 + Primary 字 | 56 |
| 禁用态 | 灰底 + 白字，不可点 | — |

主按钮左右边距 32；胶囊按钮可全圆。

---

## 七、全屏规范

| 类型 | 结构 |
| :--- | :--- |
| 标准全屏页 | 状态栏(44) + 导航栏(88) + 内容区 + 底部安全区 |
| 沉浸式全屏 | 无导航栏，内容铺满（图片/视频流） |
| Tab 页 | 状态栏 + 内容区 + 底部 Tab 栏(100+安全区) |

---

## 八、二级界面规范

| 元素 | 规范 |
| :--- | :--- |
| 导航栏 | 高 88，左返回箭头(40)，居中标题(32) |
| 返回手势 | 左上角返回 / 下滑（浮层） |
| 内容区 | 上边距 24，左右 32 |
| 底部操作栏 | 固定底部，高 120 + 安全区 |

---

## 九、弹窗规范

| 类型 | 规范 |
| :--- | :--- |
| 居中弹窗 | 宽 600，圆角 24，标题 32 + 内容 28 + 主次按钮 |
| 底部弹窗 | 顶部圆角 24，高度自适应，底部滑入 |
| Toast | 居中/底部，圆角 8，深色半透明底 + 白字，2s 消失 |
| 确认弹窗 | 居中，左「取消」右「确认」(Primary) |

---

## 十、图标规范

| 项 | 规范 |
| :--- | :--- |
| 风格 | 线性圆角图标，2px 描边，圆角端点 |
| 尺寸 | 主图标 48 / 导航 40 / 小图标 32 |
| 语义 | 按产品主题统一绘制 |

---

## 十一、圆角与间距

圆角：大卡片 24 / 按钮 16 / 小元素 8。间距遵循 8pt 栅格（8/16/24/32/40）。

---

## 十二、组件速查

| 组件 | 规范 |
| :--- | :--- |
| 内容卡片 | 白底，圆角 24，封面 + 标题 + 副信息 + 互动栏 |
| 列表项 | 高 120，左图标/头像 + 中文本 + 右箭头 |
| 输入框 | 圆角 16，高 88，浅灰底 `#F5F5F5` |
| 标签 | 圆角 8，Primary-light 底 + Primary 字 |
| 头像 | 圆形，小 64 / 中 96 / 大 160 |
| 空态 | 居中插画 + 文案 + 动作按钮 |

---

## 十三、界面提示词格式（每个界面一条）

```
### 界面：<名称>
- 画布：1080×1920 竖屏
- 结构：<二级界面/沉浸式/Tab页；导航栏/内容区/底部操作栏>
- 布局：<从上到下的模块>
- 元素：<关键元素>
- 样式：<引用本规范：色彩/圆角/按钮>
- 文案：<关键文案>
- 提示词：<一句话生成提示词>
```
