## 可复用的三个脚本片段

**① 模块卡片重排**（一次处理 17 处）：

```python
def transform(line):
    m = re.match(r"^(- \*\*模块[^\n]*?\*\*)\s*—\s*(.*?)\s*/\s*\*\*作用\*\*：(.*)$", line)
    if not m: return None
    head, content, effects = m.groups()
    clean = lambda s: s.strip().replace("，彻底", "，").replace("彻底", "")
    out = [head]
    cps = [clean(c) for c in content.split("；") if c.strip()]
    if len(cps) > 1:
        out.append("  - **内容**："); out += ["    - " + c for c in cps]
    else:
        out.append("  - **内容**：" + cps[0])
    out.append("  - **作用**：")
    out += ["    - " + clean(e) for e in effects.split("；") if e.strip()]
    return "\n".join(out)
```

⚠️ 第一版正则写成 `— (.*?) / \*\*作用\*\*：`（`/` 前必须有空格），漏掉了 `（V3 生效）/ **作用**：` 这类写法。用 `\s*/\s*` 才不漏。
（本 skill 的 `scripts/ste_scan_cn.py --restructure-module-cards` 已内置这个正则。）

## 三个真实踩到的坑

1. **`；`→`。` 切断括号内句子** —— `（已拍板：框架 1、10；SY01 22–25）` 变成 `（…10。SY01 22–25）`，中文里很生硬。共 7 处，改为 `·` 分隔后归零。机械替换后**必须专扫一遍**。
2. **营销形容词是独立词法项** —— 扫完分号与长句后，`无缝`×1、`完美`×2 仍在，它们既不是分号也不是长句。交付时主动报「本次未覆盖的检查项」可避免来回。（`完美` 最终确认是 Perfect 分级档位名，**保留**。）
3. **范围外仍有残留** —— `接入验证/README.md` 与 `tts_samples/README.md` 不在本次范围，脚本扫上一级目录时仍有 9 处散文分号。交付时一并列出，别让用户以为全清。
